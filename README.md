# Pose Coach (standalone)

Live portrait coaching in the browser using MediaPipe Pose.

## Run on your phone
The camera only works over HTTPS (or localhost).

**GitHub Pages:** push this folder to a repo, enable Pages, open the URL on your phone.

**Local test on a laptop:** `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

Model files (`*.wasm`) must stay next to index.html. The small loader scripts come from jsDelivr.
